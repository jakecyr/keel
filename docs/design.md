# Keel visual identity

A small retro terminal identity: a pixel K, a block-letter wordmark, and warm colors. Keep layouts simple, give code room to breathe, and use plain language instead of badges or decorative emoji.

## Assets

![Keel wordmark](assets/keel-logo.svg)

<img src="assets/keel-icon.svg" alt="Keel pixel K icon" width="128" height="128">

- [Icon](assets/keel-icon.svg) — square mark for avatars and project listings; use at 32 px or larger.
- [Wordmark](assets/keel-logo.svg) — icon and name for README headers; use at 190 px or larger.

Both SVGs are self-contained, with vector lettering and fixed backgrounds for light and dark surfaces. Keep their proportions, padding, and colors intact. They don't need external fonts or images.

## Palette

| Color | Hex | Use |
| --- | --- | --- |
| Ink | `#202D32` | Text and icon background |
| Cream | `#F5EBD8` | Light background and icon stem |
| Orange | `#F28B50` | Pixel K and small accents |
| Teal | `#80B5A4` | Accent on dark surfaces |
| Deep teal | `#477A6B` | Accent on cream surfaces |

Use ink on cream for body text. Keep orange and teal for decoration, not small text. Reserve pixel lettering for the wordmark; use the platform's normal reading font and a monospace font for code.

## Writing

Lead with the next useful action. Show copyable commands in order: install, create a project, then start the agent. Put advanced options in linked guides. Describe Keel as experimental, and distinguish supported features from future plans.
